# Museu Gamificado da Evolução do Software — Web

Front-end do jogo (React + TypeScript + Vite). A API Spring Boot fica em `../backend`.

## Executar

```bash
npm install
npm run dev
```

O Vite sobe em `http://localhost:5173`.

## Scripts

- `npm run dev` — servidor de desenvolvimento
- `npm run build` — checagem de tipos e build de produção
- `npm run preview` — serve o build
- `npm run lint` — Oxlint
